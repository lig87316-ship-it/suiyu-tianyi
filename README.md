# 穗语·田医

面向黄淮麦区小麦种植户与合作社的病害预警和用药决策演示。面对同一场雨，两块播期不同的麦田应该先巡哪一块？这个原型用一个麦季的两个场景，演示从判断风险到核对收期、记录作业的过程。

**[打开网页演示](https://lig87316-ship-it.github.io/Thomas-Runner-KJP/)**

## 两分钟体验

1. 在首页点击 **开始讲解**，对比东坡麦田和西渠麦田的播期与物候。
2. 进入 **风险研判**，把 B 田的物候改为“扬花初期”，观察未来 7 天赤霉病指数的变化，展开依据并记录巡查。
3. 在 **用药核验** 中，先保存 6 月 5 日收获时的拦截记录，再试算 6 月 8 日收获。核对结果后，确认模拟作业。
4. 打开 **地块台账**，查看巡查、计划拦截和实际作业。只有确认执行的记录计入用药次数。点击 **重置演示** 可重新开始。

## 本地运行

下载仓库根目录的 `index.html`，使用浏览器打开即可。样式、脚本和示例数据都包含在文件内。

## 演示范围

天气、风险指数、产品及标签参数均为模拟数据，用于比赛讲解。当前版本在浏览器本地运行，地块物候与作业记录保存在当前浏览器中。实际田间用药需核对具体产品的登记标签和当地植保意见。
